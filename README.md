# BMC Assistant

BMC Assistant is an AI-powered assistant designed to handle user requests through a **multi-agent architecture**, where different specialized agents perform different tasks.

### Key Idea

**One Assistant → Multiple Agents → Multiple Tasks**

Each agent is responsible for a specific type of work, allowing the system to perform tasks in a modular and organized way.

## Technology Stack

* Python
* Google Gemini / Google GenAI API
* Multi-Agent Architecture
* Git & GitHub

## Project Status

Currently under development as a Software Engineering project.
